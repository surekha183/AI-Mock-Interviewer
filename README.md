# 🤖 MockMate AI

An AI-powered mock interview platform built with Django that helps users prepare for interviews through personalized AI-generated questions, resume-based interviews, and performance reports.

## 🚀 Live Demo

https://ai-mock-interviewer-7wau.onrender.com

---

## ✨ Features

- User Registration & Login
- Password Reset using Brevo Email API
- Resume Upload
- AI-Based Interview Questions
- Role & Experience Selection
- Interview Performance Reports
- Previous Interview History
- User Dashboard
- PostgreSQL Database
- Responsive UI
